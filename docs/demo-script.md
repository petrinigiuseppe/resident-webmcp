# Demo arc

The target is a calm 90–120 second presentation. The current reviewed video
is 95.968 seconds, so the structure below fits its existing timing.

## Act 1 — Hook

Show the ordinary record-store interface. State the problem: browser agents
often act behind the scenes, so the user cannot see what happened or reclaim
control at the right moment.

## Act 2 — Presence

Start Agent Mode. The page changes state and the orb becomes the agent's
presence surface. Explain that the agent is now operating in the user's space,
not in an invisible side channel.

## Act 3 — Performance

Ask for a late-night disco/house selection. Show the visible WebMCP sequence:
search, digging, focus, inspect and playback. The release cover moves into the
orb, the player follows the same selection, and the agent adds the release to
My Crate. Keep the Inspector/tool evidence readable when possible.

## Act 4 — Handover

Prepare the checkout, show the review boundary, complete the no-payment demo
purchase and finish at the copyright-safe `DEMO COMPLETE` message. Then show
that a human gesture can return the page to Human Mode.

Close on the design principle:

> Visible. Predictable. Interruptible.
