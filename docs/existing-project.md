# Existing project and challenge-period work

Resident grew out of an existing artist website and 3D record-crate
experience extended with a substantial WebMCP layer during the 2026 challenge
submission period.

The challenge work is traceable in the source history beginning with the
WebMCP foundation and license-scope work on August 26, 2026, followed by the
session state machine, Song DNA Lite, player transport, visible human
handover, crate actions, demo checkout and the final `download_release`
boundary. The submitted beta head is the dated `codex/webmcp-beta` line with
the m77 browser-audio contract and its documentation.

The pre-existing experience supplied the visual identity, 3D crate, catalog
presentation, record detail surface and human checkout path. The challenge
extension supplies the page-level `document.modelContext` adapter, 29 narrow
tools, visible agent-state mapping, conservative metadata ranking, agent-callable
player controls, reversible crate actions, demo-only checkout completion and
the human-priority return path.

This distinction is intentional: the submission demonstrates meaningful
WebMCP work added to an existing project without presenting the pre-existing
artist site or private shop data as open-source challenge code.
